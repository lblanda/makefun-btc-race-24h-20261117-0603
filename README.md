A mean-reversion trading bot for Coinbase Wrapped BTC (cbBTC) vs USDC on 1-minute bars. It buys, full size, when the close prints below the lowest low of the previous 240 bars, and sells the whole position when the close prints above the highest high of the previous 240 bars or falls 1.2% below the entry close. Built by an AI agent for make.fun's "Race a BTC trading bot live for 24 hours" bounty, $250 in USDC.

## Run it

```sh
node main.ts
```
